Fixora

WordPress block theme for home repair and handyman services. Version 1.0.0

1. Installation

  1. In WordPress go to Appearance → Themes → Add New → Upload Theme, choose fixora.zip, install and activate.
  2. After activating the theme WordPress shows a notice: Begin installing plugin (also under Appearance → Install Plugins). Click it to install and activate Fixora Core. You can also upload plugins/fixora-core.zip from the package under Plugins → Add New → Upload Plugin.
  3. Appearance → Import Fixora demo → Import demo content. This creates seven jobs, three blog posts, the Privacy Policy and Terms of Use pages, a Home page and a Blog page, and sets them as the front page and posts page. Running it again updates the same items.
  4. Settings → Permalinks → Save Changes once, so /jobs/ URLs work.

3. Job fields

Open a job and use the Custom Fields panel (enable it under Preferences → Panels if hidden). Blocks in the templates are bound to these fields with Block Bindings, so changes appear everywhere.

4. Repair request form

The Booking section uses the Repair request form block (also available as the shortcode [fixora_booking_form]). Every request is saved under Jobs → Requests, so nothing is lost if email fails, and is emailed to the site admin address. To send it elsewhere, add to a child theme:

add_filter( 'fixora_booking_recipient', function () { return 'dispatch@example.com'; } );

Prefer Contact Form 7 or WPForms? Replace the form block with their shortcode inside the Booking pattern.

5. Colors, fonts, spacing

  • Colors, font sizes and spacing are in Appearance → Editor → Styles (theme.json). Change "Blue Deep" and "Blue Text" to re-brand buttons and links.
  • Font: Inter (SIL Open Font License), bundled in the theme. No font is loaded from third-party servers.
  • Phone number and WhatsApp links are plain links in the Header, Hero, FAQ, Booking and Footer patterns; search for wa.me and tel: in the Site Editor to update them.
  • Logo: Appearance → Editor → Patterns → Header, click the logo image and replace it.
  • Block style: any Button block can use the WhatsApp style (Styles panel) for the white button with the WhatsApp icon.

6. Animations

Section reveals, the steps rail, the promise stack check marks, the reviews drift and the hero entrance are powered by GSAP (bundled). They respect prefers-reduced-motion. To disable them completely, dequeue the script:

add_action( 'wp_enqueue_scripts', function () { wp_dequeue_script( 'fixora' ); }, 20 );

7. Child theme

The package includes fixora-child.zip. Install it the same way as the theme (Appearance → Themes → Add New → Upload Theme) and activate it instead of Fixora. Put your CSS in its style.css and PHP snippets (such as the filters above) in its functions.php; parent theme updates will not overwrite them. Site Editor changes are stored in the database and stay in place either way.

8. Translation

All strings are translatable. Templates: fixora/languages/fixora.pot; plugin: fixora-core/languages/fixora-core.pot. Use Loco Translate or Poedit.
